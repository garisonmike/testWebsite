# Lab Hosting Manager

A minimal website to learn, practice and test hosting on lab VMs.

## Features
- User authentication (sign up/sign in)
- OS and web server selection
- SQLite database for data persistence
- Simple congratulations page showing your configuration

## Quick Start

1. Install dependencies:
```bash
npm install
```

2. Start the server:
```bash
npm start
```

3. Open browser:
```
http://localhost:3000
```

## Lab Environment VMs
- Windows Server 
- Ubuntu Live Server
- Kali Linux
- Ubuntu Desktop
- Windows 10 Desktop

## Tech Stack
- Frontend: HTML, CSS, Vanilla JS
- Backend: Node.js + Express
- Database: SQLite (better-sqlite3)
